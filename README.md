# Spark Unlimited Investment 官网

风险投资机构 Spark Unlimited Investment 的单页官网，中英双语。纯静态站点，没有构建步骤，也没有第三方脚本（只从 jsDelivr 加载字体）。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

**语言**：不论访客的系统语言是什么，进来都是英文。地址里加 `?lang=zh` 可以直接打开中文（方便单独分享中文链接）。页面上切换语言只在本次浏览有效，不会被记住。

## 目录

```
index.html              页面结构与全部插图（含英文默认文案，便于无脚本环境与搜索引擎读取）
assets/css/styles.css   全部样式，按板块分段
assets/js/config.js     站点配置：表单提交地址、联系邮箱
assets/js/i18n.js       中英文文案，页面文字以这里为准
assets/js/main.js       语言切换、字体等待、入场动效、首屏插图、表单等交互
assets/img/             logo 与网站图标
assets/img/team/        合伙人照片
tools/portrait.swift    合伙人照片的处理工具（抠图、统一背景、对齐、调色）
```

## 设计

**原则**：浅色、单色，靠排版与留白说话。强调色只有那枚橙色圆点。

| 项目 | 取值 |
| --- | --- |
| 底色 | 暖白 `#F4F3EF` |
| 文字 | 墨黑 `#0E0E0C`，次级 `#57564F`，辅助 `#8B8A83` |
| 强调色 | 橙 `#FF4D00`，只用在圆点上 |
| 插图里的面 | `#E9E7E1`、`#DCD9D1` |
| 深色区 | 联系我们与页脚，底色与文字互换 |
| 栅格 | 12 栏，左侧 3 栏放板块标签，正文从第 4 栏起 |

**Logo**：一个点，和从它出发的射线。点是星火，射线没有终点，对应 Spark 与 Unlimited。

**圆点的用法**：它出现在 logo、每个大标题的末尾（代替句号）、配比射线的起点和插图里，除此之外不再使用强调色。

**插图**：全部是手绘的线条 SVG，直接写在 `index.html` 里，颜色跟随所在区域（深色区里自动反白）。语言和 logo 一致：点、射线、同心弧，线宽固定 1.25 像素。

| 位置 | 画的是什么 |
| --- | --- |
| 首屏 | 左下角的圆点向右上方发出射线和一圈圈同心弧，有的射线停在某一轮，有的伸出画面 |
| 介绍 | 「星火 → 点燃 → 生长 → 无限」四个阶段；四项事实各有一个小图标 |
| 使命 / 愿景 | 托住星火的弧；穿过天花板继续向上的射线 |
| 信条 | 四个小图标：领先人群的点、穿过波动的直线、方向盘、离开人群的线 |
| 投资方向 | 芯片、产品盒子、笔尖 |
| 联系我们 | 从圆点出发的纸飞机 |

插图里的类名约定写在 `styles.css` 的「插图」一段：`.s` 是线，`.k`/`.h`/`.o` 是墨点、空心点、橙点，`.f1`–`.f3` 是面。

**首屏**：文字在左，插图在右，两块互不重叠，射线不会穿过文字。插图会随指针轻轻转动（最多 3 度），并有一枚光点沿主射线飞出。手机上插图在上、文字在下，首屏一屏放得下标题、说明和按钮。

**投资方向**：每一行的射线长度就是它在组合里的占比（70 / 20 / 10）。

**动效**：标题逐行升起、细线从左划出、正文轻微上浮、插图的射线从圆点长出。系统开启「减少动态效果」时全部关闭。

**手机上**（宽度 640 像素以内）：

- 首屏说明换成短版（`hero.ledeShort`），各板块标题下的补充说明不显示。
- 介绍里的四项事实排成两行两列。
- 投资方向默认全部收起，点那一行展开。
- 合伙人并排显示。
- 页脚不再重复导航链接。

`index.html` 里带 `hide-phone` 的元素手机上不出现，带 `only-phone` 的只在手机上出现。规则集中在 `assets/css/styles.css` 末尾的「响应式」一段。

## 管理团队

名字和职务在 `assets/js/i18n.js` 的 `team.members`（中英文各一份），`index.html` 里每人一个 `.person`。中文页的名字后面以小字跟英文名（`alt`）；英文页只显示英文名，`alt` 留空字符串。

照片在 `assets/img/team/`，720 × 720，2026 年 11 月由项目方提供原图。放到这里时统一做了以下处理，人物本身没有改动：

- 抠出人像，背景换成同一种暖灰（中心 `#E9E6DF`，边缘 `#D9D4CB`），看起来像同一场拍摄。
- 按瞳孔位置和脸的大小对齐：眼睛都在距顶 42% 的高度，脸的高度都占画面的 34%。
- 饱和度降到 90%。隋国栋的原图分辨率较低，放大后加了一点锐化；苏瑜头顶发缝处透出的原背景收掉了。

处理工具是仓库里的 `tools/portrait.swift`，只用 macOS 自带的 Vision 与 Core Image，不需要安装别的东西。增加一位合伙人时，用它处理新照片，再复制一个 `.person`，并在两份 `team.members` 里各加一项：

```bash
swiftc -O tools/portrait.swift -o /tmp/portrait
/tmp/portrait 原图.jpg assets/img/team/名字.jpg
```

原图分辨率低时加 `--sharpen 0.3`；头发边缘透出原背景时加 `--gamma 1.25`；加 `--debug 目录` 会另存一张洋红底的抠图检查图。

如果本人提出要求，请替换对应文件。

## 上线前需要替换的占位内容

- **介绍里的投资阶段、角色、周期、决策方式**：按基金实际情况调整，位置在 `about.facts`。
- **联系邮箱**：`assets/js/config.js` 里的 `emails`，现在用的是 `.example` 保留域名。
- **留资表单**：见下一节，未配置前留言不会被发送。
- **页脚合规声明**：`footer.legal`，请法务确认措辞。

## 留资表单

`assets/js/config.js` 里的 `formEndpoint` 留空时，表单处于演示模式：校验、发送中、成功状态都会正常走完，但数据不会发出，成功提示下方会显示一行说明。

填入地址后，表单以 `POST` 提交 JSON：

```json
{
  "name": "", "company": "", "email": "", "phone": "",
  "role": "founder | creator | investor | other",
  "message": "", "lang": "zh | en", "page": "", "submittedAt": ""
}
```

接口返回 2xx 视为成功。可以对接自有后端、Formspree 这类表单服务，或飞书多维表格的自动化 Webhook。表单里带有蜜罐字段 `website`，被填写时判定为机器人，不会提交。

## 修改文案

所有文字都在 `assets/js/i18n.js`，`zh` 与 `en` 结构一致，改完刷新即可。

- 标题里的 `<br>` 控制换行。
- 大标题末尾不要写句号，页面会接上圆点。
- `hero.ledeShort` 是手机上显示的短版首屏说明，改 `hero.lede` 时一起看。
- 投资方向的「关注领域」条目可以写成字符串，也可以写成 `{ t: '名称', d: '举例' }`，举例以小字排在名称下面。先进科技一栏就是这样写的：「AI 产业链」「未来产业」是基金的正式表述，小字是举例。
- 英文首屏标题的字号是按第二行「become unlimited」放得进左侧 7 栏来定的，改英文标题时留意长度。
- `index.html` 里的英文是兜底内容，改英文文案时建议同步。

## 字体

| 文字 | 字体 | 来源 |
| --- | --- | --- |
| 英文、数字、西文标点 | **阿里妈妈方圆体**（可变字重，免费可商用） | jsDelivr，完整文件约 2.9 MB |
| 中文 | **思源黑体**（Noto Sans SC，可变字重，SIL OFL 开源授权） | jsDelivr 上的 `@fontsource-variable/noto-sans-sc@5.2.5`，按字符分成约 100 片，只下载页面用到的字 |

方圆体的 `@font-face` 用 `unicode-range` 限定在拉丁字符，中文会落到思源黑体。思源黑体在同样字重下比方圆体的西文粗，所以中文大标题再减一档：首屏 200，板块标题 250，其余与英文相同（标题 300，正文 400）。

中文字体表是异步加载的（`index.html` 里的 `#cjk-font`），不阻塞首屏。页面会等首屏标题用到的字形就绪再开场，最多等 1.6 秒；超时或加载失败时回落到苹方、微软雅黑等系统黑体，页面照常可用。

正式上线前可以考虑把两套字体放到自己的服务器（国内访问 jsDelivr 偶尔不稳）。改动位置是 `assets/css/styles.css` 顶部的 `@font-face` 和 `index.html` 里的两处字体地址。

## 可访问性

- 导航、展开行、表单都支持键盘操作，焦点有明显的描边。
- 插图都是装饰，对读屏软件隐藏；四个阶段的名称是正文文字。
- 没有 JavaScript 时页面内容仍然完整可读（显示英文）。
- 导航压在深色区域上时会自动切换配色。

## 部署

站点通过 GitHub Pages 发布，地址：<https://connorqiao.github.io/spark-unlimited-investment/>

推送到 `main` 分支后会自动重新发布，通常一两分钟生效。

**搜索引擎收录**：`index.html` 的 `<head>` 里目前有一行 `<meta name="robots" content="noindex, nofollow">`，搜索引擎不会收录这个页面。联系邮箱、表单等换成真实内容后，删掉这一行再推送即可。

**绑定自己的域名**：在仓库的 Settings → Pages → Custom domain 填入域名，再到域名服务商那里按提示添加 DNS 记录。

整个目录就是站点本身，也可以直接上传到其他静态托管（对象存储加 CDN、Nginx、Vercel、Netlify 等）。
